# Delight us

Found something delightful for Enshrouded? Please add it to the list.

## How to suggest

Open an issue or pull request on [Codeberg](https://codeberg.org/ClairLibre/delightful-enshrouded) or [GitHub](https://github.com/dbt4u/awesome-enshrouded). Name the resource, its category, and, where relevant, the game version you checked it against.

## Entry format

Add one line under the right category, with a link and a short description:

```markdown
1. [Resource name](https://link_to/resource) - One short, helpful sentence.
```

- (DE) after the link marks German-language content. English is the default.
- Link directly to the project or creator page.
- Mark unofficial tools as such.
- Keep it on topic: Enshrouded and its community.

The list is curated, so not every suggestion makes it in. Every one is welcome.
